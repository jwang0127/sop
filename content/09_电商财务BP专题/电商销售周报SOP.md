# 电商销售周报SOP

标签：#电商财务BP #经营分析 #SOP

## 目的

周报用于快速发现销售、费用、毛利、库存、投放效率的短期变化，提前暴露月度结果风险。

## 输入

- 本周订单数据
- 本周退款数据
- 推广消耗
- 平台费用或预估费率
- 成本单价或毛利率
- 上周、预算、同期数据

## 推荐结构

1. 本周经营结论。
2. 销售趋势。
3. 渠道和店铺表现。
4. 品类或产品表现。
5. 推广投入和ROI。
6. 退款、售后和异常。
7. 风险、机会和下周动作。

## 核心指标

| 指标 | 说明 |
|---|---|
| 销售额 | 本周销售规模 |
| 净销售额 | 扣除退款后的收入 |
| 退款率 | 售后和收入质量 |
| 毛利率 | 商品盈利能力 |
| 推广费率 | 投放强度 |
| ROI | 投放效率 |
| 平台费用率 | 平台扣费变化 |
| 经营利润率 | 综合盈利结果 |

## 写法模板

```text
本周销售额为 [金额]，较上周 [变化]，主要来自 [渠道/品类]。利润端 [好/差/持平]，核心影响因素是 [毛利率/推广费/退款/平台费]。下周重点动作是 [动作]。
```

## 检查点

- 周报不要只写销售额，要同步看利润和费率。
- 推广数据要和销售归因口径一致。
- 异常退款、平台扣费、补发和赔付要单独披露。
- 周报结论要能转成下周动作。
