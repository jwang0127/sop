# 电商财务BP常用Excel函数

标签：#电商财务BP #Excel

## 查找匹配

| 函数 | 用途 | 常见场景 |
|---|---|---|
| XLOOKUP | 按订单号、SKU、账户ID匹配字段 | 订单匹配退款、商品匹配成本 |
| VLOOKUP | 传统查找匹配 | 老模板兼容 |
| INDEX+MATCH | 多方向查找 | 复杂模板 |

## 汇总统计

| 函数 | 用途 | 常见场景 |
|---|---|---|
| SUMIFS | 多条件求和 | 按平台、日期、费用类型汇总 |
| COUNTIFS | 多条件计数 | 订单数、退款单数 |
| AVERAGEIFS | 多条件平均 | 平均客单价、平均费率 |

## 清洗判断

| 函数 | 用途 | 常见场景 |
|---|---|---|
| IF | 条件判断 | 达播/自播、费用分类 |
| LEFT/RIGHT/MID | 截取文本 | 备注字段、编码字段 |
| TEXT | 日期和编号格式转换 | 文件字段统一 |
| TRIM/CLEAN | 清理空格和异常字符 | 平台导出字段清洗 |

## 建议

- 对订单号、SKU、达人ID等关键字段先统一格式，再匹配。
- 汇总前先保留原始导出文件。
- 复杂分类规则建议沉淀成映射表，而不是写死在公式里。
