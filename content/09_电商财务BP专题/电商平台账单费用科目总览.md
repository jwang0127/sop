# 电商平台账单费用科目总览

标签：#电商财务BP #核算 #口径

## 目的

把平台账单里的复杂扣费归集到可分析的财务项目，避免费用漏计、重复计入或错分类。

## 常见平台账单费用

| 平台账单字段/费用类型 | 建议归集项目 | 检查点 |
|---|---|---|
| 佣金、技术服务费、平台服务费 | 平台费用 | 是否按净销售额计提 |
| 支付手续费、转账手续费 | 财务费用 | 是否已包含在平台服务费中 |
| 站内广告扣款、推广消耗 | 站内推广费 | 是否含红包、赠款、返点 |
| 达人佣金、团长服务费 | 直播费用或其他线上渠道费用 | 是否与推广费重复 |
| 联合活动扣费、优惠券承担 | 站内活动费 | 是否与销售折扣重复 |
| 淘客、联盟、CPS返佣 | 其他线上渠道费用 | 是否按退款后金额重算 |
| 运费险、物流服务费 | 快递费用或履约费用 | 是否属于正常履约还是售后 |
| 赔付、罚款、发票违约 | 财务费用或营业外/异常项 | 是否需要单独披露 |
| 保证金、押金 | 往来或保证金 | 不应直接进费用 |

## 处理步骤

1. 导出平台账单明细。
2. 建立原始费用类型到财务报表项的映射表。
3. 标记收入、支出、冲回、返还。
4. 识别是否与订单、退款、推广明细重复。
5. 汇总到利润表对应项目。
6. 对新增费用类型补充归集规则。

## 检查点

- 新增费用类型是否已分类。
- 退款、冲回、返还是否符号正确。
- 推广费是否已经扣除返点或赠款。
- 押金、保证金是否误入费用。
- 平台账单金额是否能与财务入账金额勾稽。
