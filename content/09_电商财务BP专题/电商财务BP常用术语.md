# 电商财务BP常用术语

标签：#电商财务BP #口径

| 术语 | 说明 |
|---|---|
| GMV | 商品交易总额，通常未扣退款 |
| 净销售额 | 销售额扣除退款后的金额 |
| 客单价 | 销售额 / 订单数 |
| 件单价 | 销售额 / 销售件数 |
| 退款率 | 退款 / 销售额 |
| 费比 | 费用 / 净销售额 |
| ROI | 成交金额 / 推广费 |
| 达播 | 达人或外部主播带货 |
| 自播 | 品牌或店铺自有直播间带货 |
| CPS | 按成交付费 |
| CPC | 按点击付费 |
| CPM | 按千次曝光付费 |
| 返点 | 代理或平台返还的费用比例 |
| 赠款 | 平台或代理赠送的广告余额 |
| 货款 | 平台结算给商家的商品款 |
| 技术服务费 | 平台按订单或服务收取的费用 |
| 联合活动扣费 | 平台活动中商家承担的费用 |
