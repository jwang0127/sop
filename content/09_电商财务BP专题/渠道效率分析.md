# 渠道效率分析

标签：#电商财务BP #经营分析

## 目的

判断不同平台、店铺、渠道、达人或投放方式是否真正创造利润。

## 分析指标

| 指标 | 公式 | 说明 |
|---|---|---|
| 净销售额 | 销售额 - 退款 | 收入质量 |
| 毛利额 | 净销售额 - 产品成本 | 商品利润 |
| 推广费率 | 推广费 / 净销售额 | 获客成本 |
| 平台费用率 | 平台费用 / 净销售额 | 平台扣点 |
| 物流费率 | 快递费用 / 净销售额 | 履约效率 |
| 经营利润率 | 经营利润 / 净销售额 | 综合结果 |
| ROI | 成交金额 / 推广费 | 投放效率 |

## 分析步骤

1. 按渠道拆出利润表。
2. 计算收入、毛利、费用和利润率。
3. 找出收入高但利润低的渠道。
4. 找出ROI高但规模小的渠道。
5. 找出退款率、物流费率或平台费用率异常的渠道。
6. 输出增投、控费、优化或退出建议。

## 四象限判断

| 类型 | 特征 | 建议 |
|---|---|---|
| 高规模高利润 | 收入高、利润率高 | 优先保障资源 |
| 高规模低利润 | 收入高、利润率低 | 拆解成本和费用，重点优化 |
| 低规模高利润 | 收入低、利润率高 | 验证放量空间 |
| 低规模低利润 | 收入低、利润率低 | 谨慎投入或退出 |
