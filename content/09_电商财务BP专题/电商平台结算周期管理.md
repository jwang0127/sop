# 电商平台结算周期管理

标签：#电商财务BP #取数 #核算

## 目的

电商平台经常存在订单发生、退款完成、账单生成、资金结算、财务入账不同步的问题。结算周期管理用于避免跨期错配。

## 常见时间口径

| 时间口径 | 含义 | 常见用途 |
|---|---|---|
| 下单时间 | 用户创建订单时间 | 经营日报、销售趋势 |
| 支付时间 | 用户完成付款时间 | 销售额口径 |
| 发货时间 | 商品出库时间 | 成本和履约匹配 |
| 确认收货时间 | 订单完成时间 | 收入确认、结算判断 |
| 退款申请时间 | 用户发起售后时间 | 售后过程监控 |
| 退款成功时间 | 退款实际完成时间 | 退款核算 |
| 账单生成时间 | 平台生成账单时间 | 平台费用核算 |
| 结算时间 | 平台打款或扣款时间 | 现金流和对账 |

## 管理方法

1. 每个平台建立结算周期表。
2. 标明销售、退款、费用、结算款分别按哪个时间口径。
3. 对账单滞后的平台，明确日数据预估和月账单覆盖规则。
4. 跨月费用建立暂估和冲回机制。
5. 在经营分析中披露因口径和结算周期导致的不可比影响。
