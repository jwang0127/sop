# 推广投放复盘模板

标签：#电商财务BP #经营分析 #推广

## 目的

把推广复盘从“看ROI高低”升级为“看是否贡献利润、是否值得继续投”。

## 复盘对象

- 平台
- 店铺
- 品牌
- 产品线
- 推广计划
- 达人/直播间
- 投放账户
- 活动周期

## 核心结论

```text
本期投放结论：[继续加投/保持/优化后观察/缩减/停止]。
原因是：[销售贡献]、[毛利表现]、[费用效率]、[退款和履约影响]。
```

## 利润化计算

```text
净销售额 = 推广成交额 - 推广相关退款
毛利额 = 净销售额 * 毛利率
变动费用 = 净销售额 * 平台费率 + 物流费 + 其他变动费用
贡献利润 = 毛利额 - 推广消耗 - 变动费用
```

## 判断规则

| 情况 | 判断 | 动作 |
|---|---|---|
| ROI高，贡献利润为正 | 有效投放 | 可考虑加投 |
| ROI高，贡献利润为负 | 毛利或费用结构有问题 | 优化品类、价格、佣金或物流 |
| ROI低，但新客价值高 | 短期亏损换长期价值 | 需要业务确认LTV逻辑 |
| ROI低，贡献利润为负 | 无效投放 | 缩减或停止 |
| 消耗增长，销售不增长 | 投放边际效率下降 | 降低预算或换计划 |

## 复盘问题

- 这次投放带来的销售是否为增量。
- 是否只是抢了自然流量。
- 推广成交品类毛利率是否健康。
- 退款率是否高于自然订单。
- 达人佣金、平台费、物流费扣完后是否还有贡献利润。
- 是否存在投放消耗跨期或返点未处理。
