# 电商财务BP能力地图

标签：#电商财务BP

## 目标

电商财务BP不只做报表，还要能把平台规则、费用结构、经营动作和利润结果连起来。

## 能力模块

| 模块 | 要解决的问题 | 典型输出 |
|---|---|---|
| 平台取数 | 数据从哪里来，口径是否一致 | 取数SOP、数据源登记表 |
| 账单核算 | 平台费用、推广费、结算款如何核算 | 平台账单底稿 |
| 经营分析 | 为什么赚/亏，差异来自哪里 | 月报、周报、专项分析 |
| 预算预测 | 目标是否可达，资源如何配置 | 预算表、滚动预测 |
| ROI管理 | 推广是否值得继续投 | ROI底线、投放复盘 |
| 渠道效率 | 哪些渠道有效，哪些拖累利润 | 渠道利润表 |
| 风险控制 | 费用漏计、跨期、口径变化 | 风险清单、闭环待办 |

## 日常问题清单

- 本月销售额增长是否带来利润增长。
- 推广费增加是否换来有效成交。
- 平台费用率是否异常。
- 退款、退货、赔付是否吞噬毛利。
- 账单结算和经营口径是否存在时间差。
- 哪些渠道需要增投、控费或停投。
