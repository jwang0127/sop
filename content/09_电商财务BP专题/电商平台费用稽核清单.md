# 电商平台费用稽核清单

标签：#电商财务BP #核算 #检查清单

## 目的

平台费用明细复杂，容易出现漏计、重复计入、归类错误、符号错误和跨期错误。本清单用于月度财报出具前做费用稽核。

## 稽核对象

- 平台佣金
- 技术服务费
- 支付手续费
- 交易服务费
- 推广消耗
- 达人佣金
- 团长服务费
- 联合活动扣费
- 优惠券和平台补贴
- 运费险
- 赔付、罚款、违约金
- 保证金和押金
- 返点、赠款、返还

## 费用分类检查

- [ ] 平台佣金是否归入平台费用。
- [ ] 技术服务费是否归入平台费用。
- [ ] 支付手续费是否归入财务费用，而不是平台费用。
- [ ] 推广扣款是否归入站内/站外推广费。
- [ ] 达人佣金是否归入直播费用或其他线上渠道费用。
- [ ] 联合活动扣费是否归入站内活动费。
- [ ] 保证金、押金是否未误入费用。
- [ ] 赔付、罚款是否单独标记异常项。

## 符号检查

- [ ] 支出是否为费用增加。
- [ ] 返还、冲回、退款是否按正确符号处理。
- [ ] 平台账单中负数是否已按报表展示需要转换。
- [ ] 同一费用类型是否同时存在收入和支出方向。

## 重复检查

- [ ] 平台账单中的推广费是否已和广告后台消耗核对，避免重复。
- [ ] 达人佣金是否已和精选联盟/热浪/团长服务费核对。
- [ ] 优惠券承担是否已在销售额中扣除，避免再次进费用。
- [ ] 运费险是否与快递费用重复。

## 跨期检查

- [ ] 账单期间是否和经营期间一致。
- [ ] 滞后账单是否已暂估。
- [ ] 上月暂估是否本月冲回。
- [ ] 跨月退款、返佣、活动扣费是否有备注。

## 稽核输出

|---|---:|---|---|---|---|
