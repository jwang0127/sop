# 月初财报检查清单

标签：#工作节奏 #核算 #模板

## 取数前

- [ ] 确认核算期间。
- [ ] 确认本期新增或关闭的渠道、店铺、品牌、部门。
- [ ] 确认是否存在特殊大促、活动、补贴、退货或系统切换。
- [ ] 确认上月遗留问题是否已处理。

## 取数中

- [ ] 每个平台导出时间范围一致。
- [ ] 明细表字段完整。
- [ ] 导出文件按统一规则命名。
- [ ] 原始文件不直接改动，另存处理版。

## 核算中

- [ ] 销售额口径明确。
- [ ] 退款口径明确。
- [ ] 平台费用、推广费用、直播费用没有重复计入。
- [ ] 成本单价使用最新有效版本。
- [ ] 异常订单、补发订单、赔付、冲减已单独处理。

## 输出前

- [ ] 利润表合计与底稿合计一致。
- [ ] 本月与上月、预算、预测差异已解释。
- [ ] 大额异常有业务原因或待确认责任人。
- [ ] 口径变更已记录。
- [ ] 文件版本号和日期正确。
