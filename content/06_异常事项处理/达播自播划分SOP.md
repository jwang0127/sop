# 达播自播划分SOP

标签：#异常处理 #核算

## 目的

区分达人直播、机构合作、自营直播、自播投流等不同业务模式，避免收入、佣金、推广费用和利润归属混乱。

## 判断维度

- 订单来源
- 达人或主播 ID
- 推广计划
- 直播间归属
- 机构或服务商
- 佣金结算方式
- 业务负责人

## 操作步骤

1. 获取订单明细。
2. 获取达人、主播、直播间或推广计划映射表。
3. 按规则初步划分自播和达播。
4. 对无法识别订单单独标记。
5. 与业务确认例外清单。
6. 更新映射表。
7. 将划分结果写入销售和费用核算底稿。

## 检查点

- 达人 ID 或直播间 ID 是否为空。
- 是否存在自播订单被归入达播。
- 佣金和推广费是否与分类一致。
- 规则变更是否记录。
