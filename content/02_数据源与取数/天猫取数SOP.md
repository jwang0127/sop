# 天猫取数SOP

标签：#取数 #SOP #平台

## 平台入口

- 生意参谋或生E经
- 热浪引擎
- 淘宝联盟
- 阿里妈妈万相台
- 品销宝
- 阿里UD
- 千牛

## 销售额

### 计算路径

1. 剔除【宝贝标题】= 会员尊享购物金/天猫购物金。
2. 按【付款时间】求和：

```text
销售额 = 净销售额（已扣退款，分摊邮费优惠等） + 退款额
```

### 达播/自播区分

热浪引擎 -> 个人中心 -> 未出账订单 -> 筛选【全部订单】->【支付时间】选择财报期间 -> 查询 -> 下载报表。

用热浪引擎订单匹配生E经订单：

- 匹配上：达播。
- 未匹配上：自播。

## 退款

1. 剔除【宝贝标题】= 会员尊享购物金/天猫购物金。
2. 按【付款时间】求和【退款额】。
3. 用热浪引擎订单匹配生E经订单，区分达播/自播。

## 平台费用

```text
平台费用 = （销售额 - 退款）* 3%
```

## 其他线上渠道费用：淘宝联盟

### 取数路径

推广 -> 推广中心 -> 淘宝联盟 -> 数据分析 -> CPS订单明细。

### 计算路径

```text
金额 = 订单金额 - 维权订单金额
```

其中：

- 订单金额：对应日期内，【来源或淘客昵称】包含“旗舰”时，取【佣金】* 0.1 + 【服务费金额】；否则取【佣金】 + 【服务费金额】。
- 维权订单金额 = 【应退回服务费】 + 【应退回佣金】。

店铺区分：

- 热浪引擎订单未匹配上：自播店铺。
- 热浪引擎订单匹配上：达人直播店铺。

## 站内推广费：阿里妈妈万相台

### 计算路径

1. 两个文件分别筛选【收支类型】= 支出。
2. 筛选【交易类型】= 扣款。
3. 选择交易日期。
4. 求和【操作金额】。
5. 两个文件的【操作金额】相加。

## 品销宝

### 取数入口

`http://branding.taobao.com`

### 计算路径

求和【交易金额】。

## 站外推广费：阿里UD

### 计算路径

1. 根据广告账户ID和投放媒体匹配账户对应店铺。
2. 根据媒体及代理信息确认代理商返点。
3. 以店铺+日期为单位计算：

```text
站外推广费 = 现金消耗 / (1 + 代理商返点) + 赔付赠款消耗
```

## 直播费用：热浪引擎

按【订单支付时间】，分组【达人昵称】求和【佣金】。

## 财务费用

```text
财务费用 = （销售额 - 退款）* 0.8%
```

## 站内活动费：千牛

站内活动费 = 页面上的【实际总花费】。

## 检查点

- 购物金类商品需剔除。
- 达播/自播依赖热浪订单匹配，需保留未匹配清单。
- 淘宝联盟佣金规则需区分“旗舰”来源。
- 阿里妈妈、品销宝、阿里UD不要重复计入。
