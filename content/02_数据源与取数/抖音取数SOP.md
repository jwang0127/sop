# 抖音取数SOP

标签：#取数 #SOP #平台

> **使用前核验：**本页的 2.5%、10%、100%、0、代理商返点和 1.05 等是原资料中的业务计算规则，不代表所有品牌或期间通用。先核对本期合同、平台账单、财务口径和生效日期；不同返点公式不能混用。若无法确认，先保留原始金额和差异，不直接写入正式利润表。

## 平台入口

- 抖店商家后台
- 精选联盟
- 电商罗盘
- 巨量引擎工作台
- 巨量千川
- 星图

原始资料提示需区分达播。

## 销售额

### 达播区分路径

1. 匹配财报系统中的达播信息维护。
2. 通过出单机构匹配 KOC 达人。
3. 归属为 KOC 达人的视为自播，其他为达播。
4. 如果同一达人既有 KOC 又有达播，再根据商品ID区分。

## 退款

### 取数路径

售后 -> 售后工作台 -> 完结时间选择财报月/日 -> 查询 -> 导出售后单。

### 计算路径

1. 筛选【售后状态】= 退款成功。
2. 退款金额 = 【退商品金额】 + 【退运费金额】 + 【退支付优惠】 + 【退税费金额】。
3. 用订单号匹配销售额订单数据，区分达播/自播。
4. 如果不区分达播/自播，可使用电商罗盘按时间筛选的退款金额。

## 快递费用

### 计算路径

1. 【动账方向】筛选出账。
2. 【备注】用前4位筛选【保费扣除】及【拦截费】。
3. 求和【动账金额】。

## 平台费用

```text
平台费用 = （销售额 - 退款）* 2.5% - 实际免除佣金
```

如果品牌比例不同，使用对应品牌比例。

## 直播费用

```text
直播费用 = 佣金比例 * 预估佣金 + 预估服务费
```

### 佣金比例

用精选联盟订单的【订单ID】匹配财报抖音订单【子订单号】：

- 匹配上，且【作者账号】包含品牌名：佣金比例 = 10%。
- 匹配上，但【作者账号】不含品牌名或为空：佣金比例 = 100%。
- 匹配不上：佣金比例 = 0。

### 预估佣金

用联盟订单的【订单ID】匹配财报抖音订单【子订单号】：

- 匹配上：预估佣金 = 精选联盟【预估佣金支出】。
- 匹配不上：记为0。

### 预估服务费

用团长服务费的【订单ID】匹配财报抖音订单【子订单号】：

- 匹配上：预估服务费 = 团长服务费【预估服务费收入】。
- 匹配不上：记为0。

## 其他品牌营销费用

### 取数路径

巨量引擎 -> 巨量千川 -> 品牌广告或竞价广告 -> 切换对应账户 -> 筛选数据统计周期 -> 取消耗。

### 计算路径

- 品牌广告：筛选时间取消耗。
- 人群种草：筛选时间 -> 计划 -> 搜索“人群种草” -> 取消耗。

## 站外推广费

### 取数路径

千川品牌自助流水表 -> 账户 -> 巨量千川 -> 品牌广告 -> 选择全部 -> 右上角选择 T-1 -> 查询 -> 下载。

### 计算路径

先去掉品牌消耗，再按通用或品牌口径计算。

品牌口径：

```text
品牌消耗 = (现金消耗 + 共享钱包消耗) * (1 - 代理商返点)
        + 赠款消耗 + 共享赠款消耗 + 消返红包消耗 + 立减红包消耗
```

通用口径：

```text
广告消耗（扣返后） = (现金消耗 + 共享钱包消耗) / (1 + 代理商返点)
                 + 赠款消耗 + 共享赠款消耗 + 消返红包消耗 + 立减红包消耗
```

## 星图费用

### 取数路径

星图 -> 任务 -> 任务管理 -> 导出数据。

注意：需要单独跳页全选数据，品牌可根据任务量选择导出范围。

### 自营视频

1. 达人昵称带品牌字样，视为自营视频。
2. 视频实际发布时间选择财报自然月。
3. 自营手续费 = 投放花费 - 投放花费 / 1.05。

### 达人任务

1. 发布时间自然月往前推两天。
2. 达人手续费 = 投放花费 - 投放花费 / 1.05。
3. 达人消耗 = 投放花费 / 1.05。

## 实际免除佣金

### 取数路径

电商罗盘 -> 商品卡分析 -> 流量分析 -> 看流量 -> 截图 -> 填写【实际免除佣金】。

## 检查点

- 达播/自播规则需保留映射表。
- 退款需用订单号回匹配销售订单。
- 平台费用要扣除实际免除佣金。
- 精选联盟、团长服务费、星图、千川不要重复计入。
- 返点计算要使用对应期间的代理商返点。
