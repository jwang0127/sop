# 京东POP取数SOP

标签：#取数 #SOP #平台

## 平台入口

- 京麦商家PC端
- 京准通
- 京挑客

## 京麦订单结算

### 取数路径

京麦 -> 财务 -> 订单结算查询 -> 单据范围选全部 -> 结算状态选全部 -> 筛选订单下单时间为财报时间 -> 查询 -> 下载明细。

统一处理：

- 剔除【结算状态】= 不结算。

## 销售额

1. 剔除【结算状态】= 不结算。
2. 【费用名称】筛选货款。
3. 【收支方向】筛选收入。
4. 汇总【应结金额】。

## 退款

1. 剔除【结算状态】= 不结算。
2. 【费用名称】筛选货款。
3. 【收支方向】筛选支出。
4. 汇总【应结金额】，金额合计转正数。

## 平台费用

### 支出侧

筛选【收支方向】= 支出，【费用名称】包括：

- 佣金
- 价保扣款
- 京豆
- 尾款佣金
- 定金佣金
- 价保返佣
- 交易服务费
- 平台券价保补贴
- 平台券价保补贴佣金

按【订单下单时间】求和【应结金额】。

### 收入侧

筛选【收支方向】= 收入，【费用名称】包括：

- 佣金
- 价保扣款
- 京豆
- 尾款佣金
- 定金佣金
- 价保返佣
- 交易服务费

按【订单下单时间】求和【应结金额】。

### 符号处理

```text
平台费用 = 支出侧 + 收入侧
```

- 若结果 < 0，转正数。
- 若结果 > 0，转负数。

## 京准通：站内推广费

### 取数路径

京准通账户中心 -> 财务记录 -> 消费记录 -> 选择交易日期时间为财报期间 -> 选择“现金” -> 交易类型全选 -> 下载。

### 计算路径

- 不含联合活动扣费。
- 求和【支出】。

## 站内活动费

筛选【交易类型】= 联合活动扣费，按【交易日期】求和【支出】。

## 京挑客：其他线上渠道费用

按【费用时间】筛选，求和【结算金额】。

## 检查点

- 京东POP和京东自营不要混用口径。
- 京麦结算明细需剔除不结算。
- 平台费用要注意收入侧和支出侧的符号。
- 京准通推广费要剔除联合活动扣费，避免和站内活动费重复。
