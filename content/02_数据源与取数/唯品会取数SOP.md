# 唯品会取数SOP

标签：#取数 #SOP #平台

## 销售额

### 日数据版

汇总两个销售额来源，求和后作为日销售额。

### 月账单版

使用日数据当月合计，后续用月账单更新。

## 退款

### 日数据版

```text
退款 = 销售额 / (1 - 拒退率) - 销售额
```

按【时间】汇总退款。

### 月账单版

```text
退款 = 销售额 - 收入小计
```

取数路径：

唯品商家后台 -> 账务信息 -> 结算平台 -> 账单管理 -> 账单一览表 -> 筛选账单类型为经销对账单V2 -> 筛选账单期间为下月 -> 明细下载。

说明：账单期间滞后一个月，例如核算7月财报时，需导出账单期间为8月的账单。

收入小计计算：

1. 汇总各账单内的销售明细、客退明细、其他明细。
2. 根据品牌名称区分本品牌数据。
3. 收入小计 = （销售明细结算含税金额 + 客退明细结算含税金额 + 其他明细结算含税金额）/ 0.7。

## 平台费用

```text
平台费用 = （销售额 - 退款）* 30%
```

## 站内推广费

### Target-Max、唯直达、唯智展、唯触点

对每个子账户分别计算：

1. 【账户】筛选对应子账户。
2. 【备注】筛选包含“账户扣费”，分别求和【现金支出】、【奖励支出】。
3. 【备注】筛选“主账户转入”，求和【奖励收入】，结果作为负数。
4. 推广费 = 第2步 + 第3步。

## 站外推广费

### 达人卖货

1. 【账户】筛选“子账户(达人卖货)”。
2. 【备注】筛选包含“账户扣费”。
3. 分别求和【现金支出】、【奖励支出】、【现金收入】。
4. 推广费 = 现金支出 + 奖励支出 - 现金收入。

### 其他推广账户

腾讯广告、线下直投、巨量引擎、移动精选等账户按站内推广费同类逻辑处理：

```text
推广费 = 账户扣费支出 + 主账户转入奖励收入
```

## 站内活动费

### 日数据版

参照上月数据，求和优惠券金额。

### 月账单版

```text
站内活动费 = 活动折扣明细中的应扣供应商活动费用金额 + 会员价保明细中的供应商实际承担金额
```

按【业务发生日期】汇总。

## 检查点

- 唯品会账单通常滞后一个月，需明确取数期间。
- 每月10日、15日可用月账单版更新上月日数据版。
- 子账户间不要重复计入。
- 主账户转入奖励收入需按负数处理。
