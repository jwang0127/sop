# 猫超取数SOP

标签：#取数 #SOP #平台

## 平台入口

- 猫超相关商家后台

## 销售额

### 计算路径

1. 【费用类型】筛选【货款】。
2. 【业务单据类型】剔除【采购退货】。
3. 按【业务时间】汇总【含税金额】。
4. 匹配运营提供的达播后端商品编码：
   - 匹配上：达播。
   - 未匹配上：自播。
5. 商家仓根据【货品名称】字段所含品牌确定对应店铺。

## 退款

### 计算路径

1. 【费用类型】筛选【货款】。
2. 【业务单据类型】筛选【采购退货】。
3. 匹配运营提供的达播后端商品编码：
   - 匹配上：达播。
   - 未匹配上：自播。
4. 按【业务时间】汇总【含税金额】。
5. 商家仓根据【货品名称】字段所含品牌确定对应店铺。

## 平台费用

### 计算路径

1. 筛选【费用类型】=【毛保】、【毛利补贴返还】。
2. 匹配运营提供的达播后端商品编码，区分达播/自播。
3. 根据【业务时间】按日汇总【含税金额】。
4. 结果取反。
5. 商家仓根据【货品名称】字段所含品牌确定对应店铺。

## 线上渠道费用

### 取数路径

普通登录 -> 商家类型选择商品供应商 -> 二级供应商选择对应品牌供应商 -> 进入商家 -> 结算管理 -> 对账单确认与查询（新）-> 选择供应商 -> 选择账单日 -> 查询 -> 明细导出 -> 最近下载 -> 下载文件。

### 计算路径

筛选费用类型包括：

- 营销活动-淘客
- 营销活动-淘客团长服务费
- 售前客服服务费
- 售后客服服务费
- 88VIP用户权益折扣
- 淘客U选返佣
- 消费者退款赔付
- 评价有礼服务费
- 赠品补差
- 先用后付服务费

求和【含税金额】。

## 检查点

- 达播后端商品编码映射表需由业务确认。
- 平台费用结果需取反。
- 商家仓按货品名称识别品牌时，要保留未识别清单。
