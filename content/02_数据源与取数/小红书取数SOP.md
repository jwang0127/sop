# 小红书取数SOP

标签：#取数 #SOP #平台

> **使用前核验：**4% 平台费率和单均 0.16 快递费用是原资料中的示例或日度估算。月度正式版应对照本期合同与结算账单；销售筛选支付时间但按创建时间归期，需确认该期间规则后再与其他平台合并。

## 平台入口

- 小红书商家或投放相关后台。

## 销售额

剔除【支付时间】为空的数据，按【订单创建时间】汇总【商家应收金额（支付金额）】作为销售额。

## 退款

求和【申请售后金额（元）】。

## 平台费用

```text
平台费用 = （销售额 - 退款）* 对应店铺比例
```

原始资料示例比例：

```text
平台费用 = （销售额 - 退款）* 4%
```

## 快递费用

### 取数路径

账单管理 -> 结算账单 -> 月度结算单 -> 选择账单周期 -> 下载账单 -> 获取运费宝。

### 日数据估算

```text
快递费用 = 销售额订单数 * 0.16
```

## 直播费用

- 日数据：选择对应达人订单，按（销售额 - 退款）* 对应费率。
- 月数据：求和分销佣金。

## 站外推广费：蒲公英

### 计算路径

1. 根据【合作名称】中的品牌或业务关键词确定店铺。
2. 根据【发布时间】求和【合作金额（含服务费）】。

## 站外推广费：聚光

### 计算路径

1. 筛选【操作类型】= 消费扣款。
2. 筛选【资金类型】= 现金。
3. 取【发生金额】。
4. 金额 = 【发生金额】 / （1 + 返点）。

## 检查点

- 店铺比例是否为本期有效比例。
- 蒲公英合作名称是否能准确识别店铺。
- 聚光返点是否使用对应期间版本。
- 直播费用日数据和月数据不要重复计入。
