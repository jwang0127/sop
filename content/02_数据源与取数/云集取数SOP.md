# 云集取数SOP

标签：#取数 #SOP #平台

## 平台入口

- 云集商家后台

## 销售额

### 日数据版

1. 订单编号剔除重复单号。
2. 汇总【会员应付金额】。

### 月账单版

按【签收时间】汇总：

```text
销售额 = 货品金额 - 商家优惠金额
```

## 退款

### 日数据版

1. 订单编号剔除重复单号。
2. 售后状态选择【全部售后】。
3. 汇总【会员应付金额】。

### 月账单版

按【退款时间】汇总：

```text
退款 = 退款金额 - 商家优惠金额
```

## 平台费用

### 日数据版

每月1日求和上月平台费用，除以本月天数，得到本月每日预估平台费用。

### 月账单版

```text
平台费用 = 平台使用费 + 交易服务费 + 年度服务费
```

其中：

```text
平台使用费 = 发货子表平台使用费累加 - 退款子表平台使用费累加
交易服务费 = 发货子表交易服务费累加 - 退款子表交易服务费累加
年度服务费 = 费用单子表费用金额累加
```

每三天用月账单版数据更新前三天日数据版数据。

## 快递费用

汇总【退货运费补贴】子表的【退货运费补贴金额】。

## 检查点

- 订单编号需去重。
- 日数据平台费为预估，需用月账单滚动更新。
- 退款口径需区分售后状态和退款时间。
