# 考拉海购取数SOP

标签：#取数 #SOP #平台

## 销售额

选择【销售明细】子表，按【结算日期】汇总【商品实付】。

## 退款

选择【退款明细】子表，按【结算日期】汇总【实退现金】。

## 平台费用

### 取数路径

1. 财报系统 -> 日收支 -> 筛选所属年月日、店铺、报表项为销售额和退款。
2. 考拉合作伙伴系统 -> 结算中心 -> 账单管理 -> 结算日期选择前30日 -> 查询 -> 邮件导出明细 -> 登录邮箱下载。

### 计算路径

基础估算：

```text
平台费用 = （销售额 - 退款）* 6%
```

账单明细：

选择【汇总账单】sheet，累加以下字段：

- 商家综合服务费
- 短信费
- 分享赚红包
- CPS返佣
- 广告营销费

每日导出文件通常只有一条数据。

## 达播直播费用

### 数据来源

达播充值及消耗明细表。

### 计算路径

1. 一条表格数据对应一条日收支数据。
2. 取【金额】字段绝对值作为财报数据值。
3. 取【店铺】字段作为财报店铺名称。
4. 取【项目说明】字段作为备注。
5. 财报所属日期取【消耗月份】当月最后一天。
6. 以所属日期 + 店铺名称 + 报表项 + 主题 + 备注作为唯一性进行更新和生成日收支。

## 站外推广费

数据来源：品牌单数据登记。

### 计算路径

1. 费用类型初始报表项为“站外推广费”，如有修改需在规则设定表更新。
2. 按登记每日同步至日收支。
3. 同步日期范围为同步日期以及前40天。
4. 表格数据和日收支一一对应。

## 检查点

- 销售额和退款按结算日期归属。
- 平台费用可先用比例估算，再用账单覆盖。
- 达播直播费用需保证唯一性字段不重复。
- 站外推广费依赖登记表同步，需检查同步状态。
