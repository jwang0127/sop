# 快手取数SOP

标签：#取数 #SOP #平台

> **执行状态：部分待补。**销售与退款的完整导出路径尚未记录；5% 平台费率和返点公式属于原资料口径，必须与本期合同、账单及生效日期核对。销售部分先筛支付时间、再按创建时间汇总，需明确这是有意采用的期间口径，否则与支付口径不能直接比较。

## 平台入口

- 快手小店
- 原始资料提到需区分达播/自播。

## 销售额

### 取数路径

原手册未补充完整菜单路径，需后续在实际后台补齐。

### 计算路径

1. 删除【订单支付时间】为空的数据。
2. 【渠道】筛选【自营】【超级链接竞价】【授权推广】作为自播。
3. 按【订单创建时间】汇总求和【实付款】。

## 退款

### 取数路径

原手册未补充完整菜单路径，需后续在实际后台补齐。

### 计算路径一

整单退款：

1. 【实付款】与【退款金额】一致，求和【商家实收金额】。
2. 【实付款】与【退款金额】不一致时，如【商家实收金额】=【退款金额】，求和【商家实收金额】。
3. 【实付款】、【商家实收金额】、【退款金额】均不一致，且订单状态为交易关闭时，求和【商家实收金额】。

部分退款：

1. 不满足整单退款情形的订单视为部分退款。
2. 【实付款】=【商家实收金额】时，求和【退款金额】。
3. 【实付款】与【商家实收金额】不一致时，退款影响 = （商家实收金额 - 实付款）*（退款金额 / 实付款）。

### 计算路径二

筛选售后状态为“售后成功”，汇总求和【退款金额】。

## 平台费用

```text
平台费用 = （销售额 - 退款）* 5%
```

## 直播费用

### 订单数据取数路径

订单管理 -> 订单查询 -> 近6个月订单 -> 更多筛选 -> 下单时间选择财报月 -> 查询 -> 批量导出 -> 标准报表。

### 计算路径

1. 用销售额订单中的【订单编号】匹配退款订单中的【退款金额】。
2. 每笔订单直播费用 = 【预估推广者分佣比例】*（实付款 - 退款金额）。
3. 根据【渠道】区分自播/达播：自营、超级链接竞价、授权推广为自播，分销为达播。
4. 团长数据按【订单实际结算时间】求和【团长佣金】+【达人佣金】，取达播店铺。

## 站外推广费

### 取数路径

账户分析 -> 磁力金牛-全站推广 -> 分日报表 -> 选择财报日 -> 查询 -> 下载。

### 计算路径

1. 根据广告账户ID和投放媒体匹配账户对应店铺。
2. 根据媒体及代理信息确认返点。
3. 以店铺+日期为单位计算：

```text
推广费 = (现金花费 + 信用花费 + 前返花费 + 后返花费) / (1 + 返点)
```

## 快递费用

求和【服务费用】。

## 检查点

- 是否正确区分达播/自播。
- 渠道字段是否完整。
- 退款是否与订单匹配。
- 站外推广返点是否使用对应期间版本。
