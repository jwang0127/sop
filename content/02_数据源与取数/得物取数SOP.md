# 得物取数SOP

标签：#取数 #SOP #平台

## 平台入口

- 得物商家后台
- 得物引力

## 销售额

### 日数据版

1. 筛选【品牌】。
2. 【订单状态】剔除“交易失败”“待支付”。
3. 按【买家下单时间】汇总：

```text
销售额 = 价格（元） - 卖家承担优惠金额（元）
```

### 月账单版

在【销售订单】子表中：

1. 商品名称筛选品牌，不区分大小写。
2. 按【发货时间】汇总：

```text
销售额 = 商品金额 + 卖家承担优惠券金额 + 卖家承担折扣活动金额
```

## 退款

### 日数据版

1. 筛选品牌。
2. 【订单状态】选择“交易关闭成功”。
3. 退款 = 【价格（元）】 - 【卖家承担优惠金额】。

### 月账单版

在【退货退款订单】子表中：

1. 商品名称筛选品牌，不区分大小写。
2. 汇总：

```text
退款 = -商品金额 + 卖家承担优惠券金额 + 卖家承担折扣活动金额
```

再除以上月天数，得到上月每日退款。

## 平台费用

### 日数据版

1. 获取上个月总平台费用、总销售额、总退款。
2. 平台费用率 = 总平台费用 /（总销售额 - 总退款）。
3. 本日预估平台费用 = 本日（销售额 - 退款）* 平台费用率。

### 月账单版

取数路径：

商家后台 -> 财务 -> 账单管理 -> 账期对账单 -> 选择财报月 -> 查询 -> 导出 -> 下载中心下载。

计算路径：

1. 【销售订单】子表：汇总【合计平台服务费】 - 【转账手续费】。
2. 【退货退款订单】子表：汇总【合计平台服务费】 - 【转账手续费】。
3. 两者相加，得到上月每日平台费用。

## 站内推广费：得物引力

1. 【任务名称】包含品牌名，则归属对应品牌店铺。
2. 任务名称无品牌的，对应当月有推广品牌均摊。
3. 筛选【交易状态】= 支付(扣款)。
4. 求和【交易金额】。

## 财务费用

```text
财务费用 = （销售额 - 退款）* 1%
```

## 站内活动费

### 月账单版路径

商家后台 -> 财务 -> 账单管理 -> 账期对账单 -> 选择财报月 -> 查询 -> 导出。

### 计算路径

```text
站内活动费 = 销售订单每日联合营销费 + 退货退款订单每日联合营销费
```

结果取相反数。

## 检查点

- 日数据版平台费为预估，月账单版需覆盖更新。
- 商品名称筛选品牌时要注意大小写和简称。
- 无品牌任务名称的推广费分摊规则需记录。
