# 朴朴取数SOP

标签：#取数 #SOP #平台

## 销售额

筛选【商品名称】区分品牌：

```text
销售额 = 销量 * 供货价
```

## 退款

筛选【商品名称】区分品牌：

```text
退款 = 实际退货量 * 供货价
```

## 其他线上渠道费用

求和金额并取绝对值。

## 平台费用

```text
平台费用 = （销售额 - 退款）* 19.2%
```

另根据【所属期】字段，求和每日【金额】。

## 快递运费

### 取数路径

店铺平台 -> 财务结算 -> 其他费用单 -> 创建时间选择财报日/月 -> 费用单项目选择仓储服务费、逾期管理费。

### 计算路径

日数据：

```text
快递运费 = （销售额 - 退款）* 3.5%
```

月数据按取数路径覆盖更新。

## 检查点

- 商品名称是否能准确区分品牌。
- 日数据为估算，月数据需覆盖更新。
- 平台费用的比例是否为当前有效比例。
