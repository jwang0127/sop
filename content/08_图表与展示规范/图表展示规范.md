# 图表展示规范

标签：#经营分析

## 基本原则

- 一个图只表达一个核心结论。
- 标题要写结论，不只写指标名称。
- 金额单位、期间、口径要明确。
- 不要堆太多颜色。
- 重要差异要标注。

## 常用图表

| 场景 | 推荐图表 |
|---|---|
| 趋势变化 | 折线图 |
| 结构占比 | 堆积柱状图、条形图 |
| 预算差异 | 瀑布图、柱状图 |
| 业务单元对比 | 横向条形图 |
| 指标拆解 | 瀑布图、桥图 |

## 检查点

- 坐标轴单位是否清楚。
- 数值标签是否过密。
- 颜色是否有含义。
- 是否能一眼看出重点。
- 图表是否与正文结论一致。
