# 财务BP通用知识库

这是一个面向财务BP、经营分析、预算预测、月度财报核算工作的通用 Obsidian 知识库。

它不是某一家公司的操作手册，而是一个可复用的工作系统：

- 用 `00_首页与导航` 做日常入口。
- 用 `01_工作节奏` 管理月度、季度、年度节奏。
- 用 `02_数据源与取数` 沉淀各平台和系统的取数方法。
- 用 `03_财报核算` 管理收入、退款、费用、成本等核算口径。
- 用 `04_经营分析` 支撑月度经营分析报告。
- 用 `05_预算与预测` 支撑预算、滚动预测和差异分析。
- 用 `06_异常事项处理` 记录高频例外事项。
- 用 `90_模板` 新增统一格式的 SOP、检查清单和分析页。

## 使用方式

1. 打开 Obsidian。
2. 选择“打开本地仓库”。
3. 选择这个文件夹：`财务BP通用知识库`。
4. 从 `00_首页与导航/首页.md` 开始使用。

## 维护原则

- 一页只解决一个问题。
- 每个 SOP 都写清楚：什么时候用、输入是什么、怎么做、输出什么、怎么检查。
- 公司专属信息放进 `92_资料索引` 或 `93_附件`，不要写死在通用 SOP 里。
- 高频错误单独沉淀到对应页面的“常见问题”。
- 任何口径变化都要记录变更日期和影响范围。
