# 财报核算总流程

标签：#核算 #SOP

## 目标

把各数据源加工成可解释、可追溯、可复核的经营利润表。

## 流程

1. 确认组织和期间。
2. 收集销售、退款、费用、成本等底稿。
3. 统一字段和口径。
4. 按项目核算。
5. 按组织、渠道、产品或部门汇总。
6. 做勾稽检查。
7. 做波动分析。
8. 输出报表和问题清单。

## 核算项目框架

| 模块 | 常见项目 | 重点风险 |
|---|---|---|
| 收入 | 销售额、退款、净销售额 | 期间错位、退款漏匹配 |
| 成本 | 产品成本、履约成本 | 单价版本错误、SKU匹配失败 |
| 平台费用 | 佣金、技术服务费、交易手续费 | 费用类型重复或漏计 |
| 推广费用 | 站内推广、站外推广、达人费用 | 归因口径不一致 |
| 直播费用 | 坑位费、服务费、佣金 | 达播/自播分类错误 |
| 管理费用 | 人力、办公、折旧、分摊 | 分摊规则不透明 |
| 财务费用 | 手续费、贷款利息、汇兑 | 入账期间不一致 |

## 输出要求

- 能追溯到原始数据。
- 能解释关键波动。
- 能说明口径变化。
- 能指出待业务确认事项。
